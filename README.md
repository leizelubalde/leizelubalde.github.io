# Leizel Ubalde Portfolio Website | Publication Build

## Preview
Open `index.html` in a browser. Keep `styles.css`, `script.js`, `favicon.svg`, and `assets/` in the same folder structure.

## Publish free on GitHub Pages
1. Create a public GitHub repository named `leizel-portfolio`.
2. Upload **all files and the assets folder contents** from this folder to the repository root.
3. In Settings > Pages, choose Deploy from a branch, `main`, `/ (root)`, then Save.
4. Wait for the live URL shown in Pages. It will normally look like `https://YOUR-USERNAME.github.io/leizel-portfolio/`.
5. Test the live URL on desktop and mobile, including images, navigation, demo, email links, and resume PDF.
6. After the real URL is known, add a canonical URL and `og:url` to `index.html`. You may also add an `og:image` hosted at an absolute HTTPS URL for a richer LinkedIn preview.

## How the site works
- The demo is an illustrative local browser simulation. No CRM or emails are connected.
- The inquiry form opens the visitor's email app with a draft. Visitors must press Send; there is no backend or stored submissions.
- Service packages are proposed offerings and should be scoped with each client.
- The KUMA results are combined outcomes from multiple marketing and website improvements, not attributable to any single automation.
